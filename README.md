# Glancit

Glancit is a simple and powerful browser extension for translation and text analysis.

## English

### Key Features
- Quick translation and analysis using AI models.
- Minimalist UI that stays out of your way.
- Privacy-focused: **No data collection** (Data is only sent to translation services as requested).

### Privacy & License
- **Privacy**: Glancit does not collect any personal data. Text is sent to external services only for translation. For more details, see [PRIVACY_POLICY.md](./PRIVACY_POLICY.md).
- **License**: This project is licensed under the MIT License. See [LICENSE](./LICENSE) for details.

## 한국어

### 주요 기능
- AI 모델을 이용한 빠른 번역 및 분석.
- 방해되지 않는 최소한의 UI.
- 프라이버시 중심: **데이터 수집 없음** (번역 요청 시에만 외부 서비스로 데이터가 전송됩니다).
